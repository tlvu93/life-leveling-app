# Alpha 2: Breadth and Guides Test

> **ARCHIVED 2026-08-15.** This test predates the roadmap-centered Creator and
> Explorer model. See the current DJ/VJ prototype plan in `docs/product`.

- Status: Ready to test
- Journeys: Sports + Creative, Starting Fresh, finite Guide discovery, private/unlisted route creation

## Decisions this test should make

1. Can a person with Sports + Creative signals find and complete a plausible Quest without the product implying that they need elite sports ability or public posting?
2. Can a person who cannot name interests, hobbies, or strengths use two small attempts to discover an honest next signal?
3. Does a five-Guide deck increase inspected or started Quests without becoming a bookmarking loop?
4. Can people distinguish a shared Guide, their private Build, and a canonical Path?

## Participants

Recruit 6–10 adults, including:

- at least two who select Sports + Creative;
- at least two who initially select no interests and Starting fresh;
- people who make plans for themselves and people who have previously shared learning or hobby routes with friends;
- a mix of one-hour and multi-hour weekly availability.

This test does not recruit children or simulate child accounts. Family safety and parental controls remain a separate scope decision.

## Session tasks

1. Complete onboarding without coaching the participant toward a particular signal.
2. Explain the first two recommendations in their own words.
3. Start one playable Quest and return after a real attempt to reflect.
4. Review one finite Guide session. Ask why they saved, passed, or inspected each Guide.
5. Create one private route, make it unlisted, and explain who they would or would not share it with.
6. Ask whether the route should become a public Guide or canonical Path, and what evidence they would expect first.

## Measures

| Signal | Result |
| --- | --- |
| Profile felt truthful | Yes / Partial / No |
| First recommendation felt plausible | Yes / Maybe / No |
| Started a real Quest | Yes / No |
| Reflected after attempting | Completed / Deliberately stopped / Did not attempt |
| Guide cards viewed | 1–5 |
| Guide inspected before decision | Count |
| Guide saved | Count |
| Saved Guide became a started Quest | Yes / No |
| Understood why the deck stopped | Yes / No |
| Understood private vs unlisted | Clear / Partial / No |
| Understood Guide vs Path | Clear / Partial / No |
| Largest trust concern | Free text |

Time in app and total swipes are diagnostic only. The success behavior remains a reflected real-world attempt that changes the route.
